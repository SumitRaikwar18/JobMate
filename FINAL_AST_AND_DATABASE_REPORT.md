### Source Provenance Retention
Every AST observation generated by `ASTEvidenceExtractor` retains complete engineering provenance:
- `repository`: e.g. `owner/repo`
- `filePath`: relative source path (e.g. `src/api/users.ts`)
- `commitSha`: verified commit SHA
- `sourceRange`: `startLine`, `endLine`, `startColumn`, `endColumn`
- `sourceUri`: e.g. `https://github.com/owner/repo/blob/sha/src/api/users.ts#L14-L38`
- `contentHash`: SHA-based cache key for incremental re-analysis
- `technologies`: exact language, framework, and database tokens
- `evidenceLevel`: strictly assigned (`L4_SOURCE_CODE` for implementation, `L6_TEST_CI` for verified test suites)

## 6. Remaining Factual Limitations

1. **Languages Beyond the Core 6**: Languages outside TypeScript, JavaScript, Python, Java, Go, and Rust (such as C++, C#, Kotlin, Swift, Ruby, PHP) fall back to manifest dependency analysis (`L3_MANIFEST_DEPENDENCY`) until dedicated syntax tree query grammars are added.
2. **Third-Party API Rate Limits**: GitHub unauthenticated REST API requests are capped at 60/hr unless a `GITHUB_TOKEN` is configured in `.env`.
3. **Macro Expansion in Rust/C**: Highly complex procedural Rust macro expansions or C-preprocessor macros are parsed structurally at definition site rather than after full compiler macro expansion.
